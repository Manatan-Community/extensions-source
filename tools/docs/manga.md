# Manga Sources

Use `MangaSource` for chapter-based image or page content.

The example source demonstrates:

- popular and latest listings
- search
- details
- chapters
- lazy page image resolution
- processed image output
- archive pages
- text pages
- alternate covers
- URL/deep-link handling
- filters and preferences

Shared helpers live in `shared/manatan-shared/src/manga.rs`.
