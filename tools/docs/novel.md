# Novel Sources

Use `NovelSource` for chapter-based text or reader HTML.

The example source demonstrates:

- popular and latest listings
- search
- details
- chapters
- paged chapter lists
- reader HTML with images and CSS
- image request headers
- API/JSON fixture parsing
- authenticated/server-token settings through preferences
- URL/deep-link handling
- filters and preferences

Shared helpers live in `shared/manatan-shared/src/novel.rs`.
