# Video Sources

Use `VideoSource` for episodic or item-based playable media.

The example source demonstrates:

- popular and latest listings
- search
- details
- episodes
- hoster extraction and resolution
- HLS streams with subtitles and audio tracks
- WebView-style signature extraction from fixture HTML
- torrent, magnet, and debrid metadata
- URL/deep-link handling
- filters and preferences

Shared helpers live in `shared/manatan-shared/src/video.rs`.
