# MangaDex attribution

This compiled Rust/Wasm source adapts the behavior of the MangaDex extension in
`keiyoushi/extensions-source`, path `src/all/mangadex`, under Apache-2.0.

The implementation calls MangaDex's public API directly. It does not package,
load, or execute Android bytecode or downloaded code. MangaDex and its marks
belong to their respective owners; this community source is not affiliated
with or endorsed by MangaDex.
